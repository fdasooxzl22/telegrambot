# Solana Wallet Copy Trading Analyzer Bot 🤖

Telegram бот для анализа Solana кошельков и определения их перспективности для копитрейдинга.

## 🌟 Возможности

- 📊 Анализ истории транзакций Solana кошельков
- 📈 Оценка торговой активности и стабильности
- 💰 Проверка текущего баланса
- 🎯 Рекомендации по копитрейдингу (оценка 0-100)
- 🔍 Простой интерфейс через Telegram

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.11+
- Docker и Docker Compose (опционально)
- Telegram Bot Token (получить у [@BotFather](https://t.me/botfather))

### Установка

1. **Клонировать репозиторий**
```bash
git clone https://github.com/fdasooxzl22/telegrambot.git
cd telegrambot
```

2. **Настроить переменные окружения**
```bash
cp .env.example .env
# Отредактируйте .env и добавьте свой TELEGRAM_BOT_TOKEN
```

3. **Запуск с Docker (рекомендуется)**
```bash
docker-compose up -d
```

**ИЛИ запуск без Docker**
```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить бота
python bot.py
```

## 📖 Использование

### Команды бота

- `/start` - Показать приветствие и инструкции
- `/help` - Справка по использованию
- `/analyze <адрес_кошелька>` - Анализировать кошелек

### Примеры

```
/analyze 7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU
```

Или просто отправьте адрес кошелька боту:
```
7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU
```

## 📊 Что анализирует бот

Бот анализирует следующие метрики кошелька:

1. **Количество транзакций** - общее количество операций
2. **Период активности** - как долго кошелек активен
3. **Частота торговли** - сколько транзакций в день
4. **Текущий баланс** - количество SOL на кошельке
5. **Последняя активность** - время последней транзакции

## 🎯 Система оценки

Бот присваивает кошельку оценку от 0 до 100:

- 🟢 **70-100**: Рекомендуется для копитрейдинга
- 🟡 **40-69**: Средняя перспективность, требуется дополнительный анализ
- 🔴 **0-39**: Не рекомендуется для копитрейдинга

## 🔧 Конфигурация

### Переменные окружения

- `TELEGRAM_BOT_TOKEN` (обязательно) - токен вашего Telegram бота
- `SOLANA_RPC_URL` (опционально) - URL Solana RPC (по умолчанию: mainnet-beta)

## ⚠️ Важные замечания

- Это базовый инструмент анализа и не является финансовым советом
- Всегда проводите дополнительное исследование перед копитрейдингом
- Бот анализирует только публичные данные блокчейна Solana
- Оценка основана на алгоритмических метриках и может не отражать реальную прибыльность
