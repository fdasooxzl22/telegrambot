# Telegram Bot для продажи прокси Minecraft

## Описание
Telegram бот для продажи прокси серверов Minecraft с реферальной системой, профилем пользователя и интеграцией платежей через Crypto Bot.

## Функции

### 🔗 Реферальная система
- Уникальная реферальная ссылка для каждого пользователя
- Бонус 5₽ за каждого приглашенного друга
- Статистика рефералов в профиле

### 👤 Профиль
- Просмотр баланса
- Статистика рефералов
- Активные прокси
- Промокоды
- Пополнение баланса

### 🛒 Покупка прокси
Доступные типы прокси:
- **FunTime** - 26₽
- **HolyWorld** - 36₽
- **SpokyTime** - 20₽
- **Любой сервер** - 40₽

### 💳 Методы оплаты
- **Crypto Bot** (автоматическая обработка)
- **Telegram Stars** (через администратора)
- **FunPay** (через администратора)
- **СПБ/RU карта** (через администратора)

### 🎁 Система промокодов
- Активация промокодов
- Начисление бонусов на баланс

## Установка

1. Установите Python 3.8 или выше

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте токены в файле `telegram_bot.py`:
   - `BOT_TOKEN` - токен вашего Telegram бота
   - `CRYPTO_BOT_TOKEN` - токен Crypto Bot API
   - `ADMIN_USERNAME` - username администратора

4. Запустите бота:
```bash
python telegram_bot.py
```

## Конфигурация

### Токены
```python
BOT_TOKEN = "ваш_токен_бота"
CRYPTO_BOT_TOKEN = "токен_crypto_bot_api"
ADMIN_USERNAME = "@ваш_username"
```

### Прокси типы и цены
Настраиваются в словаре `PROXY_TYPES`:
```python
PROXY_TYPES = {
    'funtime': {'name': 'FunTime', 'price': 26},
    'holyworld': {'name': 'HolyWorld', 'price': 36},
    'spokytime': {'name': 'SpokyTime', 'price': 20},
    'anyserver': {'name': 'Любой сервер', 'price': 40}
}
```

### Реферальный бонус
```python
REFERRAL_BONUS = 5.0  # Бонус в рублях
```

## База данных

Используется SQLite с следующими таблицами:
- `users` - пользователи
- `referrals` - реферальная система
- `proxies` - купленные прокси
- `transactions` - история транзакций
- `promocodes` - промокоды
- `promocode_usage` - использованные промокоды

База данных создается автоматически при первом запуске в файле `bot_database.db`.

## Использование

### Команды бота
- `/start` - запуск бота и главное меню
- `/start <referral_code>` - запуск с реферальным кодом

### Навигация
Бот использует inline-клавиатуру для навигации:
- Главное меню с кнопками
- Подменю для каждого раздела
- Кнопки "Назад" для возврата

### Процесс покупки
1. Нажмите "🛒 Купить прокси"
2. Выберите тип прокси
3. Выберите метод оплаты
4. Оплатите (автоматически через Crypto Bot или вручную через администратора)
5. Получите прокси в разделе "📦 Мои прокси"

### Реферальная система
1. Откройте "🔗 Реферальная система"
2. Скопируйте свою реферальную ссылку
3. Отправьте друзьям
4. Получайте 5₽ за каждого нового пользователя

## Troubleshooting

### Бот не запускается
- Проверьте правильность токена бота
- Убедитесь, что установлены все зависимости
- Проверьте версию Python (требуется 3.8+)

### Ошибки оплаты через Crypto Bot
- Проверьте токен Crypto Bot API
- Проверьте подключение к интернету
- Убедитесь, что API токен активен

### База данных не создается
- Проверьте права на запись в директории
- Убедитесь, что sqlite3 установлен

## Дополнительная информация

Для добавления промокодов используйте прямые SQL запросы к базе данных:

```sql
INSERT INTO promocodes (code, amount, uses_left) 
VALUES ('PROMO2024', 50.0, 100);
```

Где:
- `code` - текст промокода
- `amount` - сумма бонуса в рублях
- `uses_left` - количество использований
